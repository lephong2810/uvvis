UV-Vis Abs Finder

Tra độ hấp thụ tại một bước sóng trên nhiều file cùng lúc. File chỉ được đọc trong trình duyệt của bạn.

Thả file hoặc cả thư mục vào đây App tự lấy file Excel (.xlsx, .xls, .xlsm, .xlsb) và bỏ qua phần còn lại.
nm
Nhập nhiều bước sóng bằng dấu phẩy hoặc khoảng trắng, ví dụ 260, 280. Số lẻ viết 664.5 hoặc 664,5.
Đang hiển thị dữ liệu ví dụ (phổ xanh methylene giả lập). Dữ liệu này sẽ biến mất khi bạn thả file của mình vào.
